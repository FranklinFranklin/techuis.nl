Speed Up Windows 11 in 2025 (No Extra Software)

Practical tweaks to make a slow Windows 11 PC feel fast again—using built-in settings only.

Quick wins (5–10 minutes)

  • Disable unnecessary startup apps: Settings → Apps → Startup.
  • Storage cleanup: Settings → System → Storage → enable Storage Sense and run cleanup.
  • Reduce visual effects: Settings → Accessibility → Visual effects.

Performance tuning

  • Power mode: Settings → System → Power & battery → Power mode.
  • Background apps: Settings → Apps → Installed apps → Background permissions.
  • Update Windows: Settings → Windows Update.

If it’s still slow

  • Disk type matters: SSD upgrades are the biggest speed win if you're on HDD.
  • Full scan: Windows Security → Virus & threat protection.
  • Drivers: especially chipset + graphics + storage controller.
